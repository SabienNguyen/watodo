# watodo

**What to do, right now**

In theory, things like deep work, routines, and weekly planning boost productivity, protect mental health,
and reduce burnout. Now, for various reasons, these lifestyles do not work for people. People desire to 
create a routine that focuses on things that they want to do, such as hobbies or passion projects. The issue with this mentality is
that it makes the mundane parts of your routine the enemy. There is an urge to blame these things because 
parts of an average person's routine might include work, school, traffic, and other things that people do not
consider the "fuel" for an exciting life. Moreover, systems that use schedules that revolve around time blocks fall
apart from a lack of adaptability. I propose a system that lives in the middle of the impulsive actor and to-the-minute
planning. This system encourages people to implement routines in their lives centered around the mundane and repetitive parts 
of their schedules.

## The goal

Implement a system that allows you to commit to doing activities without a time-constrained routine.

## Running it

Needs Node.js and npm.

```sh
npm install
npm run dev      # start the app, then open the address it prints
npm test         # run the tests
npm run build    # production build
```

Built with TypeScript, React, Vite, Tailwind, shadcn/ui and TinyBase.
